## Background

Rdenticon is a port of [Jdenticon](https://jdenticon.com/) to Rust, 
a popular JavaScript library for generating [identicons](https://en.wikipedia.org/wiki/Identicon).

Created using [ril](/projects/ril), my Rust image processing library.
Used to generate default profile pictures for users on [Adapt](/projects/adapt).
