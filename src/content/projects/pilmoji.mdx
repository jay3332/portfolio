<div class="md:text-center italic">
  Emoji support for Pillow, the Python Imaging Library.
</div>

Adds emoji rendering support for PIL/Pillow, the popular Python imaging library. 
Focuses on simplicity and configurability.

## Features

- Support for all Unicode emojis and Discord emojis out of the box
- Optionally cache rendered emojis for faster performance.
- Support for custom emoji sources.
- Precise emoji sizing and alignment.
