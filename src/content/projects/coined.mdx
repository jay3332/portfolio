## Background

Coined started as a side project during the pandemic, when I was spending a lot of time on Discord and
wanted to build something fun for the communities I was part of. Economy bots existed, but most were
shallow: earn coins, spend coins, repeat. I wanted something with more depth—a virtual economy that
players could actually engage with over time.

Over five years, Coined grew from a simple bot into a fully featured economy game with a web dashboard,
image-generated cards and items, and a player-driven marketplace.

## What is Coined?

Coined is a **Discord bot** paired with a web interface that simulates a virtual economy. Players earn
coins by participating in the server, then spend them on items, gamble in minigames, trade with other
players, and invest in a simulated market.

Key gameplay elements include:

- **Earning** — daily rewards, working commands, and activity-based income.
- **Spending** — a shop with rotating item stock, upgrades, and cosmetics.
- **Trading** — a peer-to-peer marketplace where players list and buy items from each other.
- **Minigames** — gambling and skill-based games that add variance to the economy.
- **Leaderboards** — net worth rankings that drive competitive play.

## Image Generation

One of Coined's signature features is its **image-generated inventory and profile cards**, built using
[Pillow](https://python-pillow.org) (PIL). Rather than showing a plain text list of items, Coined
renders rich visual cards showing a player's coins, items, and rank—styled like a collectible card.

This was one of my first deep dives into programmatic image generation: compositing layers, rendering
custom fonts, drawing shapes, and handling alpha channels—skills that directly led me to build
[Pilmoji](/projects/pilmoji) and eventually [RIL](/projects/ril).

## Technical Architecture

The bot is written in Python using [discord.py](https://discordpy.readthedocs.io), with
[PostgreSQL](https://www.postgresql.org) as the primary datastore for player accounts, inventories,
transactions, and market listings. A lightweight [Flask](https://flask.palletsprojects.com) server
exposes a web dashboard for viewing stats and managing the economy.

### Economy Design

Balancing a virtual economy is surprisingly difficult. Without controls, runaway inflation or deflation
can make the game feel pointless. Coined uses several mechanisms to maintain balance:

- **Coin sinks** — purchases, fees on marketplace trades, and upgrade costs drain coins from circulation.
- **Rate limiting** — daily caps on earning commands prevent bots and farming.
- **Random variance** — work payouts vary within a range, adding unpredictability.

### Database Schema

Player data (balances, inventory, stats) is stored in PostgreSQL with normalized tables for items,
transactions, and market listings. Frequently accessed data like current balances and active market
prices are cached in memory to avoid hammering the database on every command.
