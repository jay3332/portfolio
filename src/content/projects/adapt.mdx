## Motivation

This initially started as a continuation of [FerrisChat](https://github.com/ferrischat),
which (after a rewrite) evolved into a completely independent codebase and project.

FerrisChat was the first OSS project I contributed to consistently, so it made sense
to continue building on that foundation.

## Infrastructure

### Rust Backend
- REST services (public API, content delivery network, and media proxy) written using axum
- CDN tags images with metadata processed using RIL (see "Projects/RIL")
- WebSocket written using tokio-tungstenite and communicates using RabbitMQ message broker
- Voice server based on WebRTC protocol

### Data Storage
- Durable models such user accounts stored using PostgreSQL, cached using Redis
- Ephemeral models such as message acknowledgements and user mentions are stored on Redis

### Front-end
- Web-based client served at https://app.adapt.chat, written using Solid.js, Tailwind CSS, and Tauri
- Landing and onboarding webpage served at https://adapt.chat, written using Astro and Tailwind CSS
