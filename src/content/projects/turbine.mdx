## Background

Pastebin sites fill a specific niche: quickly share a snippet of code or text without setting up a
full file host. Tools like [Hastebin](https://hastebin.com) are great for this—but they're barebones.
[GitHub Gist](https://gist.github.com) adds features but feels heavy for quick shares.

Turbine is the middle ground I wanted: a **modern, self-hostable pastebin** with a clean UI and
meaningful features—syntax highlighting, privacy controls, user accounts—without the overhead of a
full code collaboration platform.

## Features

- **Syntax highlighting** for dozens of languages, powered by [Prism.js](https://prismjs.com).
- **Public and private pastes** — share openly or keep for yourself.
- **Password-protected pastes** — share with a specific audience by requiring a password to view.
- **User accounts** — save pastes to your profile and manage them later.
- **Starred pastes** — bookmark pastes you want to find again.
- **Custom themes and fonts** — personalize the editor and viewer to your preference.

## Architecture

### Backend (Rust + Axum)

The backend is a Rust REST API built with [axum](https://github.com/tokio-rs/axum). Paste content
is stored in [PostgreSQL](https://www.postgresql.org) alongside metadata (language, visibility,
expiry, author). Short paste IDs are generated using a base-62 encoding of a random integer to
keep URLs compact.

Password-protected pastes store a **bcrypt hash** of the password; the raw paste content is returned
only after the client submits the correct password. This means even the server operator can't read
protected pastes without the password.

### Frontend (Next.js)

The frontend is a [Next.js](https://nextjs.org) app. The code editor uses
[CodeMirror](https://codemirror.net) for editing with syntax highlighting and theme support.
Language detection runs automatically based on file extension or content sniffing, but can be
overridden manually.

### Self-Hosting

Turbine is fully self-hostable. The backend and frontend are containerized, and the repository
includes a `docker-compose` file for a one-command setup. Configuration covers database credentials,
file size limits, and paste retention policies.
