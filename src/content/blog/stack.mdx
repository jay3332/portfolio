#### Languages

I primarily program in
<span class="font-medium text-[#dea584]"><Icon name="languages/rust" class="inline-block align-middle" /> Rust</span> and
<span class="font-medium text-[#3572a5]"><Icon name="languages/python" class="inline-block align-middle" /> Python</span>
when dealing with backend development and low-level programming. I also use
<span class="font-medium text-[#a97bff]"><Icon name="languages/kotlin" class="inline-block align-middle" /> Kotlin</span>
to write code for my FIRST robotics team.
I also use
<span class="font-medium text-[#aaaaaa]">C</span>/<span class="font-medium text-[#f34b7d]">C++</span> for competitive
programming, native bindings with Rust, and computer systems.

#### Data Management

**PostgreSQL** is my go-to database for relational data storage, while **Redis** is used for caching and session
management. I also use **RabbitMQ** as a way to pass messages and events between microservices.

#### Web Development

When developing websites, I use
<span class="font-medium text-[#3178c6]"><Icon name="languages/typescript" class="inline-block align-middle" /> TypeScript</span>
with frameworks such as
<span class="font-medium text-[#ff5a03]">Astro</span> (like this website), <span class="font-medium text-[#446b9e]">Solid.js</span>, 
and <span class="font-medium text-[#61dafb]">React</span>. Sometimes, I may also integrate my Rust projects into my
websites using <span class="font-medium text-[#624de8]">WebAssembly</span>. For styling, I primarily use **TailwindCSS** and **Sass**.
